Falta el rootfs de Alpine

Esta página arranca Alpine Linux real dentro de WebAssembly mediante el emulador v86 (JIT x86→wasm). El motor de v86 y las BIOS ya están incluidos en el repositorio; lo que falta es el rootfs de Alpine, que no se versiona por su peso y porque hay que construirlo con Docker.

Construcción del rootfs (requiere Docker en marcha):

# 1) Motor + BIOS: ya incluidos en /wasm/v86/ (no hace falta descargar nada)
#    Reproducible con:  node scripts/fetch-wasm-assets.mjs

# 2) Rootfs de Alpine (9p) desde el repo de v86
git clone --depth 1 https://github.com/copy/v86.git /tmp/v86
cd /tmp/v86/tools/docker/alpine
./build.sh          # -> images/alpine-fs.json + images/alpine-rootfs-flat/
# ./build-state.js  # -> images/alpine-state.bin.zst  (opcional, arranque instantáneo)

# 3) Copiar a este directorio
cp /tmp/v86/images/alpine-fs.json        ./
cp -r /tmp/v86/images/alpine-rootfs-flat ./
# cp /tmp/v86/images/alpine-state.bin.zst ./   # opcional

Servidor: sirve .wasm con Content-Type: application/wasm y cachea los assets con Cache-Control: max-age=86400. No se requieren cabeceras COOP/COEP en este modo (sin Web Worker con memoria compartida).
