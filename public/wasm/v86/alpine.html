Falta el rootfs de Alpine

Esta página arranca Alpine Linux real dentro de WebAssembly mediante el emulador v86 (JIT x86→wasm). El motor de v86 y las BIOS ya están incluidos en el repositorio; lo que falta es el rootfs de Alpine, que no se versiona por su peso y porque hay que construirlo con Docker.

Construcción del rootfs (requiere Docker, git y Python 3):

# 1) Motor + BIOS: ya incluidos en /wasm/v86/ (reproducible con npm run wasm:assets)

# 2) Rootfs de Alpine + escritorio i3 (docker/alpine-i3/Dockerfile)
npm run wasm:rootfs:build
#   -> public/wasm/v86/alpine-fs.json + alpine-rootfs-flat/
#   --with-node  incluye node (~46 MB más)
#   --no-trim    conserva System.map, config y /var/cache
#   --zstd       comprime los .bin (requiere el módulo zstandard)

# Alternativa sin escritorio: tools/docker/alpine/build.sh del repo copy/v86

Servidor: sirve .wasm con Content-Type: application/wasm y cachea los assets con Cache-Control: max-age=86400. No se requieren cabeceras COOP/COEP en este modo (sin Web Worker con memoria compartida).

Producción: el rootfs puede servirse desde un CDN o un release sin versionarlo aquí. Define DEFAULT_ROOTFS_BASE en esta página o pásalo en la URL con ?rootfs=https://…/ (el CDN debe permitir CORS). Para traerlo a esta carpeta en local o CI: node scripts/fetch-alpine-rootfs.mjs --base=<url>.
